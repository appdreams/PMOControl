# PMO User Guide

**Status:** Approved

## Rotina

Meu Dia → exceções → projetos → riscos/issues → ações/decisões →
milestones → status → reports.

## Princípio

Trabalhar por exceção, não abrir todos os projetos manualmente.

## Status

Revisar mudanças, validar indicadores/RAG, consolidar resumo e publicar
quando autorizado.

## Copilot

Usar para análise e preparação; validar recomendações antes de ações.
