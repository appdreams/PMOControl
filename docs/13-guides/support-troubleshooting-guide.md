# Support & Troubleshooting Guide

**Status:** Approved

## Coletar

Environment, user/tenant identifiers seguros, resource ID, timestamp,
request/correlation ID, expected/actual behavior.

## Nunca solicitar

Password, raw session token, BYOK ou integration secret.

## Diagnóstico

UI → API → authz → DB → jobs → provider/integration.

## Escalation

Segurança, tenant leakage ou data corruption são incidentes, não tickets
comuns.
