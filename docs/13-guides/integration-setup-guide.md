# Integration Setup Guide

**Status:** Approved

## Fluxo

Choose Provider → Configure → Authenticate → Define Source Authority →
Map → Validate → Activate → Monitor.

## Verificar

Scopes, credentials, external IDs, sync strategy, conflicts, retries e
audit.

## Regra

Nunca ativar integração sem definir quem é authoritative para os dados
sincronizados.
