# Tenant Administration Guide

**Status:** Approved

## Tenant Admin

Gerencia usuários, memberships, roles/scopes, parâmetros, taxonomias,
integrações e AI/BYOK conforme permissões.

## Segurança

Acesso sensível é deny-by-default.

## Rotina

Revisar acessos, usuários inativos, integrações, configurações críticas
e eventos relevantes.

## Regra

Tenant Admin não equivale automaticamente a Platform Admin.
