# Development Workflow

**Status:** Approved

## Fluxo

Issue/Requirement → Spec → Design/Architecture check → Implementation →
Tests → PR → Review → Preview → Merge → Deploy.

## Antes de codificar

Confirmar Actors, Permissions, Scope, Data Policies, Workflow, Audit e
Acceptance Criteria.

## Definition of Done

Código, testes, documentação afetada, security checks e observability
quando aplicável.
