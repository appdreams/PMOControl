# Platform Admin Guide

**Status:** Approved

## Responsabilidade

Tenants, plataforma, limites/planos, saúde operacional e suporte
autorizado.

## Restrição

Não possui acesso automático aos dados de negócio de tenants.

## Support access

Explícito, justificado, mínimo, temporário e auditado.

## Segurança

Nunca usar conta compartilhada.
