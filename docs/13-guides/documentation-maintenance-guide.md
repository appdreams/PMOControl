# Documentation Maintenance Guide

**Status:** Approved

## Atualizar

Mudança de produto → PDD/Spec. Decisão arquitetural → ADR. Mudança UX →
UX docs/reference. Schema → Data/migration. Security → Security
docs/tests. API → API contract. AI → AI docs/evaluations. Ops →
DevOps/Guides.

## Git

Histórico de versões fica no Git; evitar cópias `v1`, `v2` no nome
oficial sem necessidade.
