# Spec-Driven Development Guide

**Status:** Approved

## Regra

Cada módulo em `/docs/04-specs/NNN-feature/` define requisitos antes da
implementação.

## Arquivos padrão

README, requirements, domain-model, user-flows, business-rules,
database, api, ui, permissions, events, acceptance-criteria, edge-cases
e test-cases.

## Processo

Spec → implementação → testes derivados dos acceptance criteria →
evidência de conclusão.

## Mudança

Se comportamento muda, atualizar Spec antes ou junto do código.
