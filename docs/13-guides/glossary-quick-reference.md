# Glossary Quick Reference

**Status:** Approved

-   **Current State:** estado operacional atual.
-   **Published State:** estado oficial publicado.
-   **Snapshot:** fotografia imutável de publicação.
-   **Baseline:** compromisso aprovado.
-   **Forecast:** previsão atual.
-   **Actual:** realizado.
-   **RAG Calculated:** saúde calculada.
-   **RAG Effective:** saúde efetiva após override autorizado.
-   **Risk:** incerteza futura.
-   **Issue:** problema atual.
-   **Action:** compromisso executável.
-   **Decision:** escolha governada.
-   **Tenant:** fronteira organizacional de isolamento.
-   **Scope:** conjunto de recursos onde acesso se aplica.
