# PMO Control --- Guides

**Status:** Approved\
**Official path:** `/docs/13-guides/README.md`

## Objetivo

Centralizar guias operacionais, de desenvolvimento, administração,
governança e suporte do PMO Control.

## Público

-   Developers
-   QA
-   DevOps
-   Platform/Tenant Admin
-   PMO Admin / PMO
-   Project Managers
-   Executives
-   Support/Operations

## Princípio

Os guias explicam **como operar** o sistema. Specs continuam sendo a
fonte de verdade funcional; Architecture/ADRs definem decisões técnicas;
Security define controles obrigatórios.
