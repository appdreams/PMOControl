# Developer Onboarding

**Status:** Approved

## Sequência

1.  Ler Product Vision/PDD.
2.  Ler architecture README/system architecture.
3.  Ler conventions e ADRs.
4.  Identificar Spec do módulo.
5.  Ler UX correspondente.
6.  Ler data/security/API aplicáveis.
7.  Configurar ambiente local.
8.  Rodar migrations/seeds.
9.  Rodar testes.
10. Implementar via PR.

## Regra

Não iniciar feature apenas pela imagem da tela. O comportamento vem da
Spec.
