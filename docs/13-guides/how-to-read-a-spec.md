# How to Read a Spec

**Status:** Approved

## Ordem prática

1.  README/requirements.
2.  Domain model.
3.  Business rules.
4.  User flows.
5.  Permissions.
6.  Database/API.
7.  UI.
8.  Events.
9.  Acceptance criteria.
10. Edge/test cases.

## Pergunta final

É possível explicar ator, autorização, estado inicial, comando,
validação, resultado, audit e falhas? Se não, a implementação ainda
possui ambiguidade.
