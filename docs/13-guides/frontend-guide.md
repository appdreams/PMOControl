# Frontend Guide

**Status:** Approved

## Fonte

UX + Spec + API contracts.

## Regras

-   frontend não é security boundary;
-   permissions na UI melhoram UX, não substituem backend;
-   distinguir Current vs Published;
-   estados loading/empty/error/forbidden;
-   confirmations para ações consequenciais;
-   acessibilidade;
-   desktop-first conforme UX.

## Visual

Seguir design system e visual references existentes, sem criar
identidade paralela.
