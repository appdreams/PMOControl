# Incident Response Guide

**Status:** Approved

## Fluxo

Detect → Triage → Contain → Eradicate → Recover → Review.

## Críticos

Cross-tenant exposure, credential compromise, data corruption, audit
compromise e indisponibilidade prolongada do core.

## Pós-incidente

Root cause, ações, owners, prazos, regression tests e atualização de
threat model/runbook.
