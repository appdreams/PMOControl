# PMO Copilot Guide

**Status:** Approved

## Exemplos

-   Quais projetos merecem atenção?
-   O que mudou?
-   Quais riscos ameaçam marcos?
-   Prepare o comitê.
-   Gere resumo executivo.

## Saída

Distinguir Facts, Inferences e Recommendations quando material.

## Ações

Proposal → Review → Confirmation → Fresh Authorization → Domain Command
→ Audit.

## Limite

Copilot não amplia seu acesso.
