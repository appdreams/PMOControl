# Incident Response

**Status:** Approved

## Ciclo

Detect → Triage → Contain → Eradicate → Recover → Review.

## Classificação

Incidentes envolvendo cross-tenant exposure, credentials, unauthorized
financial/confidential access ou audit compromise são alta prioridade.

## Preservação

Preservar logs/evidências relevantes sem alterar cadeia de auditoria.

## Comunicação

Definir responsáveis, canais, escalonamento e requisitos
contratuais/regulatórios antes de produção GA.

## Pós-incidente

Root cause, impacto, ações corretivas, testes de regressão e atualização
do threat model.
