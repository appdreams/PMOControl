# Security Audit

**Status:** Approved

## Eventos

Login/security, grants/revokes, role/scope, baseline, budget, RAG
override, publication, decisions, destructive actions, sensitive export
e privileged access.

## Propriedades

-   append-oriented;
-   actor/action/resource/time;
-   tenant context;
-   correlation/request IDs;
-   before/after quando seguro;
-   reason quando requerido.

## Proibição

Não armazenar passwords, raw tokens, BYOK, integration secrets ou dados
desnecessários.

Ordinary users não podem alterar histórico de auditoria.
