# Test Pyramid

**Status:** Approved

## Unit

Funções puras, cálculos, validators, mappers.

## Domain

RAG, status transitions, baseline rules, decision workflow, permissions.

## Integration

PostgreSQL, Supabase, Storage, Inngest, adapters.

## API

Request/response, authz, errors, idempotency.

## Component

Formulários, tabelas, estados e accessibility.

## E2E

Golden paths e workflows críticos.

## Regra

E2E não deve substituir testes rápidos de domínio.
