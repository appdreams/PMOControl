# PMO Control --- UX

**Status:** Draft — behavioral traceability review in progress

## Objetivo

Esta pasta define a experiência oficial do PMO Control: arquitetura de
informação, navegação, design system, padrões de interação,
responsividade, acessibilidade e especificações das principais telas.

## Princípios

-   Update Once → Propagate Everywhere.
-   Governance by Exception.
-   Current State e Published State devem ser visualmente distinguíveis.
-   Dashboard é projeção, nunca fonte paralela de verdade.
-   Desktop-first, com experiência executiva limpa e operacional densa
    sem poluição.
-   Segurança e permissões também orientam a UX.
-   IA é assistiva, contextual e não executa ações consequenciais sem
    confirmação.
