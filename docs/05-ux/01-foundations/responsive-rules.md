# Responsive Rules

**Status:** Approved

## Estratégia

Desktop-first.

## Desktop

Left rail + conteúdo amplo; dashboards podem usar grid multicoluna.

## Tablet

Rail colapsável; cards reorganizados; tabelas preservam campos
essenciais.

## Mobile

Foco em consulta, exceções e ações rápidas. Tabelas complexas viram
cards/listas ou scroll controlado.

## Regras

-   não ocultar informação crítica apenas por breakpoint;
-   filtros avançados podem usar drawer;
-   ações primárias permanecem acessíveis;
-   gráficos devem possuir alternativa textual/resumo;
-   status workflow preserva stepper ou indicador equivalente.
