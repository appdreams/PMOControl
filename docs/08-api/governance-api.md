# Governance API

**Status:** Approved

## Resources

-   `/risks`
-   `/issues`
-   `/actions`
-   `/decisions`
-   `/dependencies`

## Risk

Create/update/assess/respond/close according to workflow.

## Issue

Create/update/resolve/close; blocker and priority explicit.

## Action

Create/update/complete/reopen where permitted; preserve source
traceability.

## Decision

Create/request/approve/reject/defer/comment according to permission and
SoD.

## Dependencies

Source and target must satisfy tenant/project authorization rules.
