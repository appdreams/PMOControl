# OpenAPI Guidelines

**Status:** Approved

## Purpose

Public/integration APIs should be representable in OpenAPI.

## Requirements

Document: - method/path; - purpose; - auth; - permissions; -
parameters; - request schema; - response schema; - errors; -
idempotency; - rate limits; - examples.

## Schema

Reuse canonical components for IDs, timestamps, money, pagination and
errors.

## Security

Documentation examples must never contain real credentials or tenant
data.
