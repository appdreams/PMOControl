# Import & Export Integration Boundary

**Status:** Approved

## Import

Upload → Staging → Validate → Preview → Confirm → Apply.

## Export

Query authorized data → field policy → format → protect output →
deliver.

## Formatos

CSV/XLSX e outros formatos podem ser suportados conforme Spec.

## Segurança

CSV formula injection, mass export, sensitive fields e tenant scope são
tratados explicitamente.
