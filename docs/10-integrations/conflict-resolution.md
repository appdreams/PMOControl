# Conflict Resolution

**Status:** Approved

## Conflito

Ocorre quando PMO Control e provider alteram dado compartilhado
incompatível.

## Estratégias

-   authoritative side wins;
-   newest version only quando semanticamente seguro;
-   manual review;
-   field-level merge;
-   reject external mutation.

## Governança

Baseline, status publicado, RAG override e decisões não usam
last-write-wins genérico.

## Registro

Conflitos relevantes devem manter contexto suficiente para diagnóstico e
resolução.
