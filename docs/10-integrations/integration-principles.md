# Integration Principles

**Status:** Approved

1.  Adapter before provider coupling.
2.  Explicit source authority.
3.  Tenant isolation.
4.  Least privilege.
5.  Idempotency.
6.  Replay safety.
7.  Observable synchronization.
8.  Conflict transparency.
9.  Graceful degradation.
10. No silent overwrite of governed state.

## Regra

Toda integração nova deve declarar dados lidos/escritos, autoridade,
autenticação, mapping, frequência, conflitos, retries, auditoria e
classificação.
