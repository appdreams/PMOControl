# Source Authority

**Status:** Approved

## Objetivo

Evitar ambiguidade sobre quem controla cada dado.

## Modos

-   PMO Control authoritative;
-   External authoritative;
-   Import-once;
-   Read-only reference;
-   Governed merge.

## Exemplo

Um Issue externo pode ser referência sincronizada, enquanto o Status
publicado continua exclusivamente governado pelo PMO Control.

## Regra

Integração nunca deve sobrescrever baseline, RAG override, publicação ou
decisão sem workflow explicitamente autorizado.
