# Disaster Recovery

**Status:** Approved

## Cenários

Database outage/corruption, deployment failure, provider outage,
credential compromise e regional/service incident.

## Prioridade

1.  preservar dados;
2.  conter impacto;
3.  restaurar core governance;
4.  restaurar async/integrations/AI;
5.  reconciliar jobs/events.

## Documentação

Runbooks e responsáveis devem ser atualizados conforme operação
amadurece.
