# Operational Metrics

**Status:** Approved

## Aplicação

Request rate, latency, errors.

## Banco

Connections, query latency, slow queries, storage.

## Jobs

Queued/running/succeeded/failed/retried, duration.

## Integrations

Sync success/failure, webhook lag, conflicts.

## AI

Latency, failures, usage/cost, validation failures.

## Produto crítico

Status publication failures e snapshot inconsistencies devem ser
zero-tolerance signals.
