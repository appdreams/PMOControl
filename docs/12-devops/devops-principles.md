# DevOps Principles

**Status:** Approved

1.  Automate repeatable work.
2.  Small and reversible changes.
3.  Build once, promote safely.
4.  Environment isolation.
5.  Security by default.
6.  Observability by default.
7.  Infrastructure complexity only with evidence.
8.  Database changes are code.
9.  Fast rollback/recovery.
10. Production access is controlled and audited.

## Regra

Redis, Kafka/RabbitMQ, Kubernetes, Elasticsearch, Neo4j e infraestrutura
distribuída permanecem fora do MVP sem necessidade comprovada.
