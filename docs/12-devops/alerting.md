# Alerting

**Status:** Approved

## Alertar

-   production unavailable;
-   sustained error spike;
-   database health critical;
-   status publication failure;
-   job failure surge;
-   integration auth outage;
-   suspected tenant isolation/security anomaly;
-   backup/recovery failure.

## Evitar

Alert fatigue.

## Severidade

Critical / High / Medium conforme impacto e urgência.

## Runbook

Alertas críticos devem apontar para procedimento operacional
correspondente.
