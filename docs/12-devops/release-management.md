# Release Management

**Status:** Approved

## Release

Conjunto rastreável de commits, migrations e mudanças de configuração.

## Antes

Quality gates e migration compatibility.

## Depois

Smoke tests, monitoring e registro.

## Comunicação

Mudanças de impacto relevante devem ter release notes internas/externas
conforme público.

## Hotfix

Segue checks mínimos obrigatórios; urgência não elimina tenant/security
gates.
