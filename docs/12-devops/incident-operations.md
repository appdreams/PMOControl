# Incident Operations

**Status:** Approved

## Fluxo

Detect → Assess → Assign → Contain → Recover → Communicate → Review.

## Prioridade máxima

Cross-tenant exposure, data corruption, credential compromise,
publication integrity e prolonged core outage.

## Evidência

Preservar logs/correlation/audit.

## Pós-incidente

Root cause, corrective actions, owner, deadline e regression tests.
