# Document AI Security

**Status:** Approved

## Documentos são conteúdo não confiável

Podem conter prompt injection ou instruções maliciosas.

## Controles

-   autorização antes do retrieval;
-   classificação/confidencialidade;
-   separar content de instructions;
-   limitar contexto;
-   não executar instruções encontradas em documentos;
-   validar citations/evidence;
-   nunca revelar documentos fora do scope.

## Upload

Processamento de IA não altera classificação do documento.
