# Fact, Inference & Recommendation

**Status:** Approved

## Fact

Derivado diretamente de dado/evidência autorizada.

## Inference

Conclusão analítica produzida a partir dos fatos.

## Recommendation

Sugestão de ação/decisão.

## UX

A interface deve permitir ao usuário distinguir essas categorias quando
a diferença for material.

## Regra

Recomendação nunca deve ser apresentada como fato consumado.
