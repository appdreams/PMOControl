# Human in the Loop

**Status:** Approved

## Consequential action

Qualquer mudança que afete estado governado relevante.

## Fluxo

`AI Proposal → Human Review → Explicit Confirmation → Fresh Authorization → Domain Validation → Command → Audit`

## Exemplos

Criar/alterar Risk, Action, Decision draft, status content ou outro
registro quando permitido.

## Proibido silenciosamente

Publish Status, RAG override, baseline change, financial approval ou
executive decision.
