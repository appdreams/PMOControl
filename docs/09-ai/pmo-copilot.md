# PMO Copilot

**Status:** Approved

## Papel

Copiloto contextual embutido na experiência do PMO Control, não apenas
chat genérico.

## Perguntas-chave

-   Quais projetos merecem minha atenção?
-   O que mudou desde o último status?
-   Quais riscos ameaçam os marcos?
-   Prepare os 5 pontos para o comitê.
-   Gere o resumo executivo.
-   Quais decisões estão bloqueando execução?

## Contexto

Tenant + usuário + scope + projeto/portfolio + período + entidades
autorizadas.

## Saída

Quando relevante: - Facts; - Inferences; - Recommendations; - Evidence
references; - Proposed actions.
