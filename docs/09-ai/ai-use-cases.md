# AI Use Cases

**Status:** Approved

## MVP

-   Pergunte ao seu projeto.
-   Resumo executivo.
-   O que mudou desde o último status?
-   Top riscos/issues.
-   Preparação para comitê.
-   Sugestão de próximos passos.
-   Draft de Status Update.
-   Draft de relatório.
-   Explicação de indicadores/RAG.
-   Identificação de pendências/exceções.

## Não MVP automático

Mudança autônoma de baseline, orçamento, RAG, decisão executiva ou
publicação de status.
