# AI Evaluation

**Status:** Approved

## Dimensões

Correctness, groundedness, relevance, completeness, instruction
following, authorization safety, hallucination rate e usefulness.

## Evaluation sets

Criar conjuntos por use case com dados sintéticos/seguros e casos
representativos.

## Regression

Mudança de prompt/model/provider deve executar avaliações relevantes
antes de promoção quando o use case for crítico.

## Human evaluation

Resumos executivos e recomendações críticas devem incluir avaliação
humana amostral.
