# Grounding & Context

**Status:** Approved

## Regra

Grounding é montado server-side a partir de dados autorizados.

## Fontes

Projects, snapshots, milestones, deliverables, risks, issues, actions,
decisions, financial/resources quando permitido, documents/evidence e
approved report context.

## Current vs Published

O contexto deve declarar se usa Current Operational State, Published
State ou ambos.

## Temporal

Perguntas como "o que mudou?" exigem comparação explícita entre pontos
temporais/snapshots.

## Minimização

Enviar ao modelo apenas dados necessários ao use case.
