# AI Action Proposals

**Status:** Approved

## Estrutura

Proposal contém target resource, intended command, proposed fields,
rationale, evidence references, confidence/limitations quando útil e
expiration/context version.

## Segurança

Proposal não é autorização.

## Staleness

Antes da execução, verificar se contexto/versão do recurso mudou. Se
mudou materialmente, exigir revisão/recalcular.

## Audit

Registrar proposta confirmada e command result quando ação for
consequencial.
